# Telegram Mini App: English widget

Та же логика, что в настольном виджете (`core.py` → `core.js`): проверка ответа, повторения (1 ч / 1 день / 3 дня),
«Уже знал», «Легко / Нормально / Трудно», цель дня 20 и серия, избранное, трудные, цикл 60 с + 10 с.
Дизайн упрощён (тёмная тема в цветах виджета, без стекла, точек и искр).

Сервера нет: страница статична, прогресс каждого пользователя хранится в облаке Телеграма
(`Telegram.WebApp.CloudStorage`) и дублируется в localStorage. Прогресс отдельный от настольного виджета.

## Файлы
- `index.html`, `style.css`, `app.js` — экран;
- `core.js` — логика (перенос `core.py`); `storage.js` — сохранение прогресса;
- `data/phrases.json`, `data/aspect.json`, `sounds/*.wav` — копии данных виджета.
  Обновить после правок базы: `python miniapp_tests/export_data.py` (из папки проекта).

## Проверка на своём компьютере
`python -m http.server 8765` в папке проекта, затем http://localhost:8765/miniapp/index.html
(быстрый таймер для проверки: `?ask=20&reveal=6`).
Тесты: http://localhost:8765/miniapp_tests/tests.html (сверка с Python) и `storage_test.html` (хранение).

## Как опубликовать
1. Выложить содержимое папки `miniapp/` на любой хостинг статических страниц с `https://`
   (GitHub Pages или Cloudflare Pages, бесплатно).
2. В @BotFather: `/newbot` (получить бота), затем `/newapp` — указать бота и адрес страницы из шага 1.
   Токен бота никому не показывать: самой странице он не нужен.
